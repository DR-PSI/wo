Work Order Anomaly & Pattern Dashboard

วิเคราะห์ความผิดปกติของงาน Work Order ของ CMMS (TRxP งานตามแผน / TRxC งานแก้ไข) เพื่อค้นหาจุดซ่อมซ้ำ งานที่ใช้เวลาผิดปกติ และแนวโน้มงานเกิดความถี่ที่ผิดปกติจากงานซ่อมบำรุง

—ยังไม่มีข้อมูล
🛠️

ยังไม่มีข้อมูล Work Order

อัปโหลดไฟล์ SAP PM Work Order (.xlsx หรือ .csv) เพื่อเริ่มวิเคราะห์ความผิดปกติ งานซ่อมซ้ำ และรูปแบบงานที่เกิดบ่อย ข้อมูลทั้งหมดประมวลผลในเบราว์เซอร์ ไม่มีการส่งออกไปที่เซิร์ฟเวอร์ใด ๆ

คอลัมน์ที่ใช้: Work Order · Description · Work Type · Status · ศูนย์งานซ่อมบำรุง · Target Start · Target Finish · Reported Date · สถานที่ติดตั้ง / MEA No.

01 จำนวนใบสั่งงานตาม Work Center
ขนาดกล่อง = จำนวน Work Order ทั้งหมด · สี = สัดส่วนงานแก้ไข (Corrective) ยิ่งแดงยิ่งสูง · ⚡ = ศูนย์งานที่มีเดือนใดเดือนหนึ่งเกิดงานแก้ไขพุ่งผิดปกติ
Corrective ต่ำ Corrective สูง ⚡ Spike ผิดปกติ
02 แนวโน้มรายเดือน: งานตามแผน vs งานแก้ไข
จำนวน Work Order ต่อเดือน แยกตามประเภทงาน
งานตามแผน (TRxP) งานแก้ไข (TRxC)
02b อัตราส่วน PM:CM รายเดือน
สัดส่วน %PM (งานตามแผน) และ %CM (งานแก้ไข) ต่องานทั้งหมดในแต่ละเดือน (ไม่นับงานสถานะ CANC) — ยิ่งแถบแดงมาก แปลว่าสัดส่วนงานแก้ไขสูงขึ้นเทียบกับงานตามแผน
%PM (งานตามแผน) %CM (งานแก้ไข)
03 อันดับความผิดปกติ (Anomaly Ranking)
รวมสัญญาณผิดปกติ 3 ประเภท: ซ่อมซ้ำจุดเดิม (Recurring) · งานพุ่งผิดปกติรายศูนย์ (Spike) · ระยะเวลาปฏิบัติงานผิดปกติ (Duration) — คลิกแถวเพื่อดูรายละเอียด
ประเภท ตำแหน่ง ศูนย์งาน สัญญาณ ความรุนแรง คำแนะนำ
04 สัดส่วนประเภทงาน
05 ลักษณะงานที่เกิดขึ้นบ่อย
คำ/อุปกรณ์ที่พบบ่อยใน Description
05b การแบ่งประเภทงาน CM
จัดกลุ่มงานแก้ไข (Corrective) ตามประเภทอุปกรณ์/สาเหตุ อ่านจาก Description — ไม่รวมงานที่ยกเลิก (CANC) และ WO ตั้งเบิกงบประจำปี/เดือน
06 สถานะงาน
